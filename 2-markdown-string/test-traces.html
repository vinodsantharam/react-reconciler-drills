What drill 2 adds to drill 1

  • Serialize once, after the commit

    Host methods only change the tree. resetAfterCommit reads the finished tree and builds the whole string, so updates, removals and moves all show up, and onChange fires exactly once.

    see 48, 49

  • Host context flows down

    getChildHostContext runs before an element's children are built, so createInstance and createTextInstance know where they are even though their parent doesn't exist yet.

    see 25, 21

  • Rules are checked in render

    A node in the wrong place throws while it's being created, before the container is touched. Updates create new nodes too, so they're checked the same way.

    see 26–36

  • React swallows errors

    It retries the render once, unmounts the root, and calls onUncaughtError. render() only throws because it collects that error and rethrows it.

    see 26, 36

  • Position is derived, never stored

    Blank lines, list numbers and indentation come from the order of children at serialization. React doesn't call anything on the siblings that shift.

    see 42, 43

  • Context also decides escaping

    Text created inside inlineCode or codeBlock gets "raw" context and stores raw: true, so the serializer leaves it alone.

    see 16, 17
