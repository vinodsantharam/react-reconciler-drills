What drill 1 adds up to

  • Render builds detached objects bottom-up: children before their parent. Nothing touches the container until commit.
  • A first mount is one appendChildToContainer per top-level node. Updates use appendChild, insertBefore, removeChild, commitUpdate and commitTextUpdate.
  • React reuses objects whenever type (and key) match. Your tests prove it with toBe, and the # numbers here show it.
  • There's no "move" method. A move is an insert of a child that's already there, so remove it first.
  • commitUpdate runs whenever the props object is new, and it owns props only, never children.
  • Children that sit directly in the root use the …Container versions of each method.
  • A throw during commit, with no error boundary, unmounts the whole root.
